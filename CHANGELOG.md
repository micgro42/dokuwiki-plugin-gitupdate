# Changelog

All notable changes to this project will be documented in this file. See [standard-version](https://github.com/conventional-changelog/standard-version) for commit guidelines.

## 1.0.0 (2026-09-06)


### Features

* warn administrators when the tracked git branch has new commits
* compare the checked out commit with the head of the branch on GitHub
* read the repository and the branch from the git directory, or set them in the configuration
* show the newest commit subject and a link to the comparison on GitHub
* set the hours between two checks in the configuration
